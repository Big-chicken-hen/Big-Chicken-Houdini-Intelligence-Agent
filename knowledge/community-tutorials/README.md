# Curated community tutorial knowledge

This pack is a community layer, not SideFX documentation. It contains original,
short workflow summaries written for this project and links to attributed
first-party creator pages. It does not copy tutorial prose, video transcripts,
course files, project files, or paid material.

Every card remains `community_unverified`. Version labels come from the creator
page when one was displayed; `unknown` means the workflow must be checked in the
active Houdini build. The local card text is Apache-2.0 with the repository.
Linked works remain under their authors' terms, as recorded in `sources.json`.

The pack is installed into the existing project-local knowledge database by the
normal explicit project refresh. It is indexed under
`source_kind=community_tutorial` so callers can include or exclude it without
changing official-only behavior.
