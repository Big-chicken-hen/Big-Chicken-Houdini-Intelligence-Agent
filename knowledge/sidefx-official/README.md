# SideFX official workflow knowledge pack

This directory contains original Big-Chicken workflow cards derived from the
linked SideFX primary sources. It does not contain copied SideFX documentation,
course transcripts, images, videos, or project files.

The cards are released under the repository's Apache-2.0 license. The linked
upstream pages remain subject to SideFX's own terms. Version-sensitive claims
must be checked against the active Houdini build and live scene behavior.

Installed Houdini help archives are indexed directly from the user's own
Houdini installation at runtime and are never copied into the repository or a
release archive.
